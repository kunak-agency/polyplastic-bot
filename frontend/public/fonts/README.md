# Шрифты

Внешних шрифтовых CDN нет: CSP разрешает только свой origin и адрес API
(инвариант «ноль внешних origin», `vite.config.ts`).

## Что здесь лежит

| Файл | Семейство | Начертание | Где |
|---|---|---|---|
| `golos-400.woff2` … `golos-600.woff2`, `golos-900.woff2` | Golos Text | 400, 500, 600, 900 | только логотип (`AppLogo.vue`), подмножество — кириллица |

## Основной текст — системный шрифт

`--font-sans` и `--font-mono` в `src/styles/tokens.css` — системные стеки.
Шаблон ждал здесь Geist, но файлы Geist в репозиторий так и не попали: браузер
получал 404 на каждой странице, а интерфейс всё равно рисовался системным
шрифтом. Все экраны проверены с ним, поэтому ссылки на несуществующие файлы
убраны.

Если захочется свой шрифт для текста: файлы `.woff2` с латиницей И кириллицей
кладутся сюда, объявляются в `src/styles/fonts.css` и ставятся первыми в
`--font-sans`. После этого — визуальный проход по всем вкладкам на ширине
1320 px: метрики шрифта меняют плотность таблиц.
