# Тональность и сбор обратной связи — ответ внешнего ресерчера (24.10)

Ответ на бриф `agency/playbook/artifacts/prompts/2026-10-24-sentiment-feedback-brief.md`. Ниже ключевое для реализации; решения оркестратора — в `agency/tasks/2026-10-24-checkpoint-feedback.md`, раздел «Волна 4».

## Архитектура
- Один вызов `/flags`, тон — поле того же ответа, отдельной модели тональности нет. **Regex не должен отменять вызов модели**: regex даёт мгновенного «кандидата», модель вызывается в фоне всегда, итог сливается (код — максимальная серьёзность, уверенность — максимальная).
- Новые поля ответа модели: `tone_confidence` 0–1, `summary` ≤ 120 символов (одна строка для HR, в третьем лице, без оценок и ПДн), `clarify_hint` (код категории для уточнения или null).
- Код проверяет `summary`: нет телефона, почты, паспорта; длина ≤ 120; для F10 — пусто. `quote` используется в карточке.
- Тон в решении об обращении не участвует. Он участвует только в агрегатах и в правиле «ранний сигнал».
- Шкала остаётся pos/neu/neg; вместо эмоций — слова «напряжённый / спокойный / позитивный». Аспект — это категория F1–F10.
- Промпт:
  - явные определения тона (`neg` — проблема, мешающая работе, даже если сказано спокойно);
  - 2 примера из голосовой расшифровки;
  - пример «спокойно: неделю нет 1С → F2, neg».

## Шаблоны уточнений (#6)
| Категория | Вопрос | Кнопки |
|---|---|---|
| F1 | «Что именно непонятно?» | Что делать · Как оценят · К кому идти |
| F2 | «Чего не хватает?» | Техника · Доступы · СИЗ/пропуск |
| F3/F4 | «С кем именно сложно?» | Наставник · Руководитель · Коллеги · Не хочу говорить |
| F6 | «Что перегружает?» | Объём · Смены/график · Нет обучения |
| F8 | «Что не совпало?» | Зарплата · График · Оформление |

- **Особые категории:** F0 — только контакты помощи; F5/F9 — только «Передать»; F10 — «Могу передать HR, если хотите».
- **Когда уточнять:** оценка ниже порога без текста; уверенность в флаге 0,3–0,6; негативный текст короче 5 слов.
- **Как часто:** не больше одного уточнения в день. Кнопка «Не хочу отвечать» → «Понял, не буду», отказом это не считается.

## Метрики (#4)
- **Набор:** 60 текстов — 20 вручную (5 голосом), 20 по шаблонам, 20 другой генерацией.
  - Тон: ~25 neg, ~25 neu, ~10 pos.
  - Флаги: по 4–6 текстов на F1, F2, F3/F4, F6, F7; по 2 на F0, F5, F9, F10; 15 без флага.
- **Метрики:**
  - тон — accuracy, macro-F1, recall neg, матрица 3×3;
  - флаги — P/R по категориям с n ≥ 4, отдельно P/R критических F0/F5/F7/F9 вместе;
  - доля ложных флагов на чистых текстах.
- **Порог «достаточно»:** тон macro-F1 ≥ 0,70, recall neg ≥ 0,80; критические флаги recall ≥ 0,85 при precision ≥ 0,60; ложных флагов ≤ 15 %.

## Роли
- **Новичок** видит строку «ответы видит HR-команда; руководитель — только общую картину» в согласии и в начале каждого опроса.
- **Тон человека** — без числа и рейтинга, руководитель тон не видит.
- **Режим «без моего имени» для F4/F5:** имя скрыто, его может раскрыть только hr_lead, с записью в журнал.
- **Чего нельзя:** индекс человека, тон в решениях по ИС, цитаты F10.

## Обратная связь
- **Пульсы:**
  - когда: вечер D0, D+5, D+14, затем раз в 2 недели, вехи D+30/60/90;
  - объём: 3 вопроса в пульсе, 5–7 в вехе;
  - шкала: 1–5 с эмодзи;
  - eNPS — только на D+60/D+90.
- **Порядок ответа:** сначала кнопки причин, текст — по кнопке «Другое».
- **Обязательные вопросы:** не больше одного на опрос. После 2 наджей — задача рекрутеру, таймлайн не блокируется дольше 48 ч.
- **Экономия времени HR:** замер секундомером «чтение текстов против карточки» на синтетике. Не называть 40 % своей цифрой.

## Демо (30–40 с) и что сказать жюри
**Демо:** пульс 2/5 → «Люди и общение» → голосовое «мастер при всех орёт» → распознано реплаем → «Передать HR без моего имени» → в кабинете F5 · P0 · ☹ · summary · цитата → у руководителя цеха только «встретьтесь 1:1» → плитка тональности → одна цифра на 60 текстах.

**Что сказать:** тон ничего не решает, решают категории; руководитель не видит текстов и тона; агрегаты только от 5 человек.

## Не проверено
- Перенос русских моделей тональности с соцсетей на HR-тексты.
- Предсказательная сила раннего тона для ухода.
- Российская правовая практика по анализу тональности сотрудников.
