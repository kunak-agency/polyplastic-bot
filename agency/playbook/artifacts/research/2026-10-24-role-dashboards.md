# Утренние дашборды по ролям — ответ внешнего ресерчера (24.10)

Полный текст ответа на бриф `agency/playbook/artifacts/prompts/2026-10-24-role-dashboards-brief.md`. Ниже — ключевое для реализации. Решения оркестратора — в `agency/tasks/2026-10-24-checkpoint-feedback.md`, раздел «Волна 2: дашборды».

## Принцип
Каждый экран строится сверху вниз, не больше четырёх блоков:
1. Список решений на сегодня, не больше 10 строк.
2. 5–6 плиток-фильтров.
3. Контекст: один график, один список.

В «Сегодня» попадает только то, где автоматика исчерпана. Пороги стартовые.

## 0. Зоны риска v2, флаг `risk_rules_v2`

**Красная** — нужно действие сегодня. Достаточно одного условия:
- открытое обращение P0;
- два низких пульса подряд (≤ 5/10) за 14 дней;
- F7 при уверенности не ниже порога;
- критический флаг F0/F5/F9, если роль его видит;
- не открыл приглашение, а выход завтра или уже прошёл;
- «не отвечает» ≥ 5 рабочих дней после 2 наджей.

**Жёлтая** — наблюдать:
- один низкий пульс за 14 дней;
- «не отвечает» 2–4 рабочих дня;
- флаг ниже порога автоэскалации;
- сообщение дважды не доставлено;
- догоняет и отстаёт на 2 дня и больше.

**Не зона:**
- обращение P1/P2 в пределах SLA;
- опрос без ответа меньше 48 ч;
- обращение с исполнителем, у которого не горит SLA.

У новичка одна зона и одна главная причина. Ожидание на демо: красная 5–10 %, жёлтая 10–15 %.

## 1. Рекрутер
**Список «Сегодня»**, 7 типов строк. Сортировка: красные выше жёлтых, дальше по дедлайну, затем по D.
- выход завтра, а приглашение не открыто;
- SLA истекает сегодня или просрочен;
- F7, новичок согласился на передачу;
- не отвечает N дней после 2 напоминаний;
- выход сегодня, а плана от руководителя нет;
- решение по ИС через 3 дня или раньше, и оно не принято;
- догоняет и отстаёт.

**Кнопки:** «Связаться» (композер + «Отметить: связался»; строка вернётся через 2 рабочих дня, если ответа так и нет), «Напомнить», «Взять», «Открыть».

**Строка «бот сам: N напоминаний, M сводок»** — то, что автоматика сделала сама.

**6 плиток-фильтров:**
| Плитка | Красная, если |
|---|---|
| Не отвечают | ≥ 3 |
| SLA сегодня — истекает / просрочен | ≥ 1 просроченного |
| Выходят — сегодня или на неделе | выход ≤ 1 дня без открытого приглашения |
| Решения по ИС ≤ 7 дней | есть без решения при D ≥ 87 |
| Низкий пульс за неделю | ≥ 20 % от ответивших |
| Догоняют | отстаёт ≥ 2 дней |

Ниже — компактный список «мои» и строка пульса за неделю: ответили, низкие, тональность при n ≥ 5.

**Не показывать:** тексты, тональность конкретного человека, обращения в SLA с исполнителем, отклик за 30 дней как плитку, чужих новичков.

**Пустое состояние** — три факта: что бот сделал сам, следующее событие с датой, сколько новичков ведёт бот.

## 2. Руководитель HR
**«Сегодня»**, 4 типа строк:
- обращения без исполнителя дольше 2 ч;
- просроченный SLA с именем рекрутера;
- новички без рекрутера;
- тема недели без ответственного.

**Действия:** «Назначить», «Переназначить», «Закрепить», «Назначить ответственного».

**6 плиток:** без исполнителя, SLA просрочен, без рекрутера, красная зона, отклик на пульс, решения по ИС на неделе.

**Таблица нагрузки:** рекрутер — новичков — открытых обращений — просроченных SLA. Сортировка по просрочкам. Время ответа по человеку не показываем, только медиану по команде; рейтингов нет.

**Карточка «Дайджест недели»** в 3 строки со ссылкой на «Аналитику». W и тональность по площадкам при n ≥ 5, со стрелкой и абсолютной дельтой. Добавлять и деактивировать рекрутеров — в Настройках. Старый «Обзор» становится страницей «Обзор площадок».

## 3. Руководитель подразделения
Кабинет ему не нужен: push в MAX плюс страница «Мои новички» по ссылке.

**На карточке:** этап, пульс уровнем 🙂/😐/☹, повод для встречи, статус 1:1, дата и статус решения по ИС.

**Кнопки:** «Встретился», «Запланировал», «Приложить план», «Решение по ИС».

**Как не выдать скрытую категорию:**
- поводы D+14 (плановая встреча), D+30 и D+87 уходят всем;
- «низкий пульс» уходит, только если в нём нет скрытых категорий;
- если скрытые категории есть — через 1–2 дня приходит нейтральный плановый повод.

**Не показывать:** тексты, обращения, категории F0/F4/F5/F9/F10, тональность числом, сравнения, агрегаты при n < 5.

## 4. СБ
Отдельного дашборда нет:
- F9 уходит в групповой чат MAX с кнопкой «Взять в работу»;
- в «Обращениях» — представление «СБ» (только F9, SLA 1 рабочий день);
- на демо его показываем под `hr_lead`;
- роль `security` — P2.

## 6. Малые числа
- При n < 20 — числа, а не проценты.
- При n < 5 — «мало данных».
- Дельта показывается абсолютной, со стрелкой.
- Точки графика с n < 5 не рисуем; по одному человеку графиков нет.
- Нули в плитках серые.

**Антипаттерны:**
- vanity-плитки;
- светофор без причины словами;
- рейтинг рекрутеров;
- больше 20 % красных строк в списке.
