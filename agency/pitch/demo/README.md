# Живое демо: HR загружает материал, и бот его отправляет

Файл: `sample-transport-GTP.pdf` (ОБРАЗЕЦ, данные условные). Сценарий «Финал. ТЗ. Чат-бот Корсик- 15.09».

1. Медиатека → запись «Материал: Проинформировать кандидата о корпоратив… (GTP)» → загрузить `sample-transport-GTP.pdf`.
2. Сценарий → шаг D−3 10:00 «Проинформировать кандидата о корпоративном транспорте» (GTP) → кнопка «Да, расскажи» → в ветке заменить текст «ты» и «вы» на «Держи маршруты и расписание 👇».
3. Опубликовать.
4. На телефоне сотрудник GTP на новой версии нажимает «Да, расскажи» у шага транспорта и получает файл.
