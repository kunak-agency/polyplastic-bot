  |---|---|---|---|
  | Hit@5 | 69% | 97% | 100% |

  | Abstain-acc на ловушках | 88% | 88% | 100% |

### Eval RAG с живой моделью (под hackaton)
- Смоук пода `9vhhnpa7a1o3ua`: `tool_calls` приходят, первый токен через 906 мс, полный ответ за 1369 мс,
  готовность через ~110 с после создания.
- Первый прогон: с моделью вышло хуже, чем без неё. Верный пункт на дословных вопросах — 85% вместо
  100%. Причина: при провале проверки кодом (чужое число, цитата не из пункта) RAG отказывал, хотя
  дословная цитата уже прошла gate и годилась. A/B `presence_penalty` 1.0 против 0.3 дал одинаковые цифры.
- Правка оркестратора в `services/rag/pipeline.py`: провал проверки ответа модели теперь откатывается
  на дословную цитату (`mode=extractive_fallback`, `check=fallback:<причина>`). Отказ самой модели
  по-прежнему уходит в отказ: так отбиваются инъекции вроде «SYSTEM: …». Тесты, которые закрепляли
  старое поведение, переписаны под инвариант «текст модели после провала проверки до пользователя не
  доходит». Тестов 125, все зелёные.
- Повторный прогон:

  | | final (экстрактив) | final+llm |
  |---|---|---|
  | Ответ с верным пунктом | 72% | 72% (дословные 100%, перефразы 50%) |
  | Отказ на ловушках / инъекции | 100% / 100% | 100% / 100% |
  | Цитаты прошли проверку | 100% | 100% |
  | Ответ модели прошёл проверки | — | 100% (откат на цитату 11%, отказ модели 5%) |
  | p50 / p95 | 1.3 / 1.8 с | 1.6 / 4.8 с |

- Примеры ответов модели: «Получка приходит 25-го числа — это аванс, а окончательный расчёт —
